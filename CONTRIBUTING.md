# Contributing to App Doctor

Thank you for helping improve App Doctor.

This public repository is for documentation, issue tracking, release information, and feedback for the closed-source App Doctor Free Beta. The product source code is maintained separately in a private repository and is not accepted here as a source-code contribution.

## Best ways to contribute

- Report reproducible bugs using the Bug Report template.
- Suggest improvements using the Feature Request template.
- Submit pull requests for corrections or improvements to public documentation and issue templates.
- Share safe, redacted report excerpts or screenshots when they materially help reproduce a problem.

## Before opening an issue

Please check `KNOWN_ISSUES.md` and the current Free Beta release notes first. For bugs, include the App Doctor version, Windows build and display scaling, target application/framework, scan configuration, expected behavior, actual behavior, and reproduction steps when available.

Maintainers assign `priority:P0` through `priority:P3` and `area:*` labels after triage. Report the real impact rather than guessing a priority.

## Security and sensitive information

Do not put API keys, credentials, private source code, confidential screenshots, personal data, or exploit details in a public issue or pull request. Follow `SECURITY.md` for security or sensitive reports.

## Pull requests

Public pull requests should stay within this repository's public scope: documentation, issue templates, release information, and related public project metadata. Do not add product source code, private validation artifacts, secrets, generated binaries, or copied third-party confidential material.

Keep changes small and focused, and explain what the change improves. By submitting material, make sure you have the right to share it publicly.
